# 홈페이지용 제목을 만듭니다

앞의 규칙을 다 지키되, 아래가 겹치면 아래를 따릅니다.

## 무엇을 드러내나

- **독자의 실무 문제와 이 글의 중심 내용**을 또렷이 드러냅니다. 대응이나 도입을 검토하는 사람이 "이건 내 얘기다" 라고 알아볼 수 있어야 합니다.
- 다루는 대상과 쟁점을 구체적으로 씁니다. 범위가 넓은 제목은 전문 콘텐츠로 안 읽힙니다.
- **검색어를 나열하지 않습니다.** 키워드는 하나면 충분하고, 문장 안에서 자연스러워야 합니다.

## 채우는 것

- `meta_description` — 검색 결과에 뜨는 설명 한 줄. **80~150자.** 제목을 다시 쓰지 말고, 이 글을 읽으면 무엇을 알게 되는지 적습니다.
- `slug` — URL 에 쓸 **영문 소문자와 하이픈.** 3~6낱말. 제목을 번역하지 말고 주제를 가리키는 낱말을 고릅니다. 한글·공백·대문자를 넣지 않습니다.

## 비우는 것

`main_keyword` 는 빈 문자열, `secondary_keywords` 와 `tags` 는 빈 배열로 둡니다. 홈페이지에는 태그가 없습니다.
